## Projects

### LeadPilot AI
A multilingual AI-powered sales assistant for interacting with prospective customers, qualifying leads, and managing follow-ups.

- Supports text and voice-based conversations in multiple languages.
- Integrates Gemini and Groq for AI-generated responses.
- Includes lead qualification, scoring, and a CRM-style dashboard.
- Provides conversation summaries and follow-up workflows.

[Live Demo](https://leadpilotaireq.netlify.app/) | [GitHub](https://github.com/pmtox/leadpilotai)

### GyChat
A full-stack messaging and community platform built with FastAPI and React.

- JWT-based authentication and user management.
- Real-time messaging using WebSockets.
- PostgreSQL integration for persistent message storage.
- Community features including posts, comments, and upvotes.

[Live Demo](https://gychat.netlify.app/) | [GitHub](https://github.com/pmtox/gyCHAT)

### Poly-TF
A multi-task Transformer implementation for image classification using PyTorch and CIFAR-10.

- Implemented image classification and rotation prediction as joint learning tasks.
- Used shared Transformer-based feature representations.
- Achieved 85.1% classification accuracy and 78.7% rotation prediction accuracy over 40 training epochs.

[GitHub](https://github.com/pmtox/poly_tf_implementation)
